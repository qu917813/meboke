## Part 1.镜像文件
Windows10镜像文件：https://1824041802.share.123pan.cn/123pan/hRnGjv-cbomA
VMWare Tools9.4.15：https://1824041802.share.123pan.cn/123pan/hRnGjv-PmNmA

# Part 2.创建虚拟机

选择**Workstaion 10.x**以及**Windows 8.x 64位**

固件类型选择BIOS

配置两个核心，3GiB内存

不适用网络连接

SATA类型硬盘

之后默认

装载镜像文件

启动时狂按F2

按照指示调日期为2014年8月10日

# Part 3.安装过程

之后正常安装即可

安装完先关机

在虚拟机目录的vmx文件添加以下参数：
time.synchronize.continue = "FALSE"
time.synchronize.restore = "FALSE"
time.synchronize.resume.disk = "FALSE"
time.synchronize.shrink = "FALSE"
time.synchronize.tools.startup = "FALSE"

另外如果tools.syncTime是TRUE，改成FALSE

然后重新启动

安装VMWare Tools9.4.15

# Part 4.隐藏应用

Windows 默认锁屏界面——通过运行 C:\Windows\explorer.exe shell:AppsFolder\Microsoft.WindowsDefaultLockScreen_8wekyb3d8bbwe!LockApp 即可进入。
云体验主机——通过运行 C:\Windows\explorer.exe shell:AppsFolder\Microsoft.CloudExperienceHost_8wekyb3d8bbwe!App 来访问
Windows Shell 体验主机——通过运行 start-menu://test/ 来访问‘

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Authentication\LogonUI\TestHooks]
"Threshold"=dword:00000001’
这个可以解锁锁屏
遇到没有的东西自己创建
